# Котик • YouTube скачать

[Открыть бота](https://t.me/KotikYouTubeVideoBot).

Пришли публичную ссылку YouTube или Shorts, затем выбери видео до 720p, до 360p
или только звук. Поддерживаются итоговые файлы до 2 ГБ; ограничения в 10 минут нет.
Качество зависит от доступных форматов исходного ролика.

Сообщения и кнопки обрабатываются на Telegram Serverless. Закрытый обработчик Railway
использует yt-dlp и FFmpeg, скачивает файл и отправляет его через локальный Telegram Bot API.
Если он недоступен, файлы до 50 МБ отправляются обычным Telegram API; большие файлы
получают понятное сообщение об отказе. Временное сообщение загрузки и файлы удаляются после
завершения. Задания выполняются по одному, чтобы объединение больших файлов не переполняло диск.
Общая очередь ограничена десятью заданиями, на пользователя — одной загрузкой.
На скачивание и отправку отводится по 30 минут.
Кеш идентификаторов Telegram хранится в памяти до перезапуска обработчика.
YouTube может отклонять запросы из дата-центров; бот сообщает о неудаче без раскрытия служебных данных.

## Развёртывание

Railway собирает корневой Dockerfile. Задай `BOT_TOKEN` и случайный `WORKER_KEY`
в переменных сервиса и включи публичный HTTPS-домен и исходящий IPv6.
Загрузчик использует IPv6 (`YOUTUBE_IPV6=1` в Dockerfile); для другой среды без IPv6
можно задать `YOUTUBE_IPV6=0`. Проверка здоровья: `/health`.
Для файлов до 2 ГБ задай `LOCAL_BOT_API_URL` с адресом сервера, запущенного с `--local`.
Доступ к `/jobs` требует заголовка `Authorization: Bearer WORKER_KEY`.

Размести папку `tgcloud/` через CLI Telegram Serverless и примени миграцию таблицы
`youtube_settings`. В закрытой базе добавь `worker_url` (HTTPS-адрес обработчика)
и `worker_key` (тот же секрет). Значения секретов не должны попадать в исходники.
Для CLI используй переменную `TGCLOUD_TOKEN`. Комментарии исходного кода — на русском языке.

Локальные проверки: `npm test`. Для проверки скачивания нужны Python, yt-dlp, Node.js и FFmpeg.
